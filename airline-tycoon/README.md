# Skyline — Airline Tycoon

Protótipo web jogável de gestão de companhia aérea.

## Recursos atuais
- Dashboard financeiro e operacional
- Mapa de rotas
- Compra e leasing de aeronaves
- Criação de novas rotas
- Demanda, ocupação, alcance e lucro por rota
- Velocidade de simulação
- Eventos aleatórios com escolhas e consequências
- Notícias da companhia
- Save automático no `localStorage`

Abra `index.html` diretamente no navegador ou publique a pasta como site estático.

> Branch criada para manter o protótipo isolado da `main` do projeto existente.

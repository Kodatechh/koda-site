# Koda Site — versão atualizada

Esta versão preserva a estrutura visual e o código-base do projeto original da Lovable.

## Ajustes aplicados
- Fonte principal alterada para Sora.
- Padronização dos nomes KodaBot e KODA OS.
- KodaBot I atualizado para Raspberry Pi Pico 2 W.
- Remoção do RTC DS3231 das informações do produto.
- Hora/data descritas como sincronizadas pela internet.
- Linha atual reorganizada para KodaBot I e KodaBot I Pro.
- KodaBot II mantido apenas como produto futuro.
- KodaBot III removido da linha atual.
- Página de comparação atualizada para KodaBot I x KodaBot I Pro.
- Informações antigas/fictícias do changelog substituídas pelo estágio atual do KODA OS 0.4.
- OTA descrito como recurso em desenvolvimento.
- Textos da home e metadados atualizados para a marca atual.

## Como rodar
Use Node.js e execute:

npm install
npm run dev

Para gerar uma build:

npm run build
